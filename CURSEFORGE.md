# BuddyBugReport – Lua Error Reports

**Project summary**

Create a copyable Lua error report with stack traces, error counts, and your addon list in one click. Supports WoW Retail and WoW Forever.

**Category**

Development Tools

**Project description**

BuddyBugReport gives you one place to collect the details an addon author needs to reproduce a Lua error. Type `/br` and click **Create report**. Copy the text into a GitHub issue or CurseForge comment after reviewing it for private details.

Each report includes the WoW edition, version, build and language, the installed addons with their versions and enablement, and up to 50 distinct Lua errors with stack traces and occurrence counts. The error history is stored locally and can be cleared in the same window.

Extract the ZIP so the `BuddyReport` folder sits inside your client's `Interface/AddOns` folder. The same package supports **WoW Retail 12.1.5** and **WoW Forever 1.60.1**. BuddyReport runs independently and leaves your Blizzard error popup setting as configured.

The addon's name in WoW is **BuddyReport**. The interface is available in English and German.
